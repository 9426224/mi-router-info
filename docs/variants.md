# 硬件批次与版本差异

同名产品换硬件的情况不少。主表对配置差异大的批次单独占一行，这里补充批次识别、换料细节和来源。购买二手或对比参数前，先看这一页确认批次。

## 小米 BE3600 系列

| 版本         | 型号        | 网口          | 主控                       | 无线                                       | 备注                                                 |
| ------------ | ----------- | ------------- | -------------------------- | ------------------------------------------ | ---------------------------------------------------- |
| 白色 2.5G 版 | RD15        | 1×2.5G + 3×1G | IPQ5312 四核 1.1GHz        | 2.4G 2x2 688M + 5G 2x2 2882M，4 颗独立 FEM | 2024.1 上市，主表单独一行                            |
| 白色千兆版   | RD16        | 4×1G          | 高通四核 1.1GHz（IPQ5312） | 同 2.4G/5G 规格，无 2.5G 口                | 2024.4 上市，首发 229 元；主表单独一行               |
| 黑色版       | RD16        | 4×1G          | 达发 AN7563PT 双核 1GHz    | MT7990AN + MT7976CN，FEM 集成              | 后期批次，功耗更低，固件与 RD15 不通用；主表单独一行 |
| Pro          | RN01 / RN04 | 1×2.5G + 3×1G | IPQ5312                    | 同 2.5G 版，带蓝牙网关/中枢网关            | 单只 349 元，套装 699 元                             |

RD16 的千兆版和黑色版型号相同但主控完全不同：前者是高通四核，后者是达发 AN7563PT + MT7990AN；两者固件也不能与 RD15 互刷。

来源：[BE3600 RD15 拆机](https://www.acwifi.net/26827.html)、[1.25A 版本](https://www.acwifi.net/34321.html)、[黑色版拆机](https://www.acwifi.net/34369.html)、[千兆版上市](https://www.pcpop.com/article/6845304.shtml)、[版本对比](https://www.shunot.com/miwifi/954.html)。

## 小米 AX3000T

| 版本 | 型号   | 主控    | 交换/存储/内存 | 备注                                                           |
| ---- | ------ | ------- | -------------- | -------------------------------------------------------------- |
| v1   | RD03   | MT7981B | 原版料         | 2023.8 上市，可刷 OpenWrt，支持小米 WiFi App                   |
| v2   | RD03   | MT7981B | 已换料         | 仍为联发科方案，但交换芯片、闪存、内存均已更换；具体料号未确认 |
| v3   | RD03v2 | IPQ5018 | 256M / 128M    | 2025.6 起换高通方案，散热缩水，仅米家 App；主表单独一行        |

v1 与 v2 外观、型号相同，只能通过批次或拆机区分；v2 的固件与早期版本不完全通用。v3 是另一套高通方案，内存/闪存容量相同，但 CPU 从四核 1.3GHz 降到双核 1GHz。

来源：[高通版拆机](https://www.acwifi.net/32952.html)、[OpenWrt RD03v2](https://github.com/ADCDS/openwrt-xiaomi-ax3000t-rd03v2)、[换料讨论](https://bbs.nga.cn/read.php?tid=44508372)。

## 小米 BE6500 / BE6500 Pro

| 型号       | 型号代号 | 内存 | 闪存 | 中枢网关 | 天线     |
| ---------- | -------- | ---- | ---- | -------- | -------- |
| BE6500     | RN02     | 512M | 128M | 无       | 6 根外置 |
| BE6500 Pro | RD08     | 1G   | 512M | 有       | 5 根内置 |

BE6500 可以看作去掉网关、增加外置天线的版本，5G 都是 QCN6224 4x4。

BE6500 Pro 在 2025 年出现过换料批次，包装、标签和型号都不变：

- 内存从南亚换成力积电，闪存从华邦换成兆易创新，FEM 从高通换成无标型号。
- 散热片由 254g 减到 149g，减重约 41%。
- 主控、1GB 内存、4 个 2.5G 口和无线规格不变，但长时间负载下的散热余量变小。

主表把 2023 初版和 2025.4 起批次分开记录，购买二手或对比时以批次为准。

来源：[BE6500 拆机](https://www.acwifi.net/30388.html)、[BE6500 Pro 拆机](https://www.acwifi.net/27123.html)、[换料报道](https://www.eet-china.com/news/202507092957.html)。

## 小米万兆 AX10000 与 BE10000 Pro

| 型号         | 主控                  | 内存         | 网口           | 存储         | 上市    |
| ------------ | --------------------- | ------------ | -------------- | ------------ | ------- |
| 万兆 AX10000 | IPQ9570 四核 2.2G A73 | 2G DDR4-3200 | 2.5G×4 + SFP+  | 无 M.2       | 2022.12 |
| BE10000 Pro  | IPQ5424 四核 1.8G A55 | 2G DDR4      | 10G×2 + 2.5G×4 | M.2 + USB3.0 | 2025.9  |

BE10000 Pro 的 CPU 主频更低，但有 40TOPS NPU，多了万兆电口和 M.2；两者不是简单升级关系。
