# 维护指南

## 添加或修正型号

数据只有一份：[`data/routers.csv`](../data/routers.csv)。改它，其余内容自动生成。

### 方式一：Excel / WPS / Numbers

1. 打开 `data/routers.csv`（编码选 UTF-8）。
2. 在末尾新增一行，按表头填写。
3. 另存为 CSV（UTF-8），保留英文逗号分隔。

单元格里含有逗号、双引号或换行时，表格软件会自动加引号，无需手动处理。

### 方式二：GitHub 网页

打开 `data/routers.csv`，点右上角铅笔图标，直接在末尾追加一行，提交即可。提交后 CI 自动重建图片与网页。

### 方式三：本地文本编辑器

注意保持 21 列、英文逗号分隔；含逗号的字段用双引号包起来，例如 `"2x2 574M, 4K-QAM"`。

## 字段约定

| 列                     | 说明                              | 示例                                                      |
| ---------------------- | --------------------------------- | --------------------------------------------------------- |
| 路由器名称             | 商品名                            | 小米AX6000                                                |
| 型号                   | 背板型号，多型号用 `/`            | RA72                                                      |
| 上市时间               | `YYYY.M.D`；只查到月份写 `YYYY.M` | 2020.12.28                                                |
| SOC                    | 主控芯片                          | IPQ5018                                                   |
| 频率/架构              | 核心数、主频、架构                | 2C 1G A53                                                 |
| NPU/加速               | NPU / NSS / HWNAT 等硬件加速      | NPU 2×1.7GHz / HWNAT / CTF（部分）                        |
| 内存 / 内存型号        | 容量与颗粒型号                    | 512M DDR3L / 钰创EM6HE16EWAKG-10H                         |
| 存储 / 存储型号        | 容量与颗粒型号                    | 128M / 兆易创新GD5F1GQ4REYIG                              |
| 2.4G 芯片 / FEM / 无线 | 2.4G 无线方案                     | 集成 / 2× QPF4288 / 2×2 · 40MHz · 574Mbps · 1024-QAM      |
| 5G 芯片 / FEM / 无线   | 5G 无线方案                       | QCN6224 / 4× QPF4559 / 4×4 · 160MHz · 5765Mbps · 4096-QAM |
| 天线                   | 数量、内置/外置与频段分配         | 7 根外置（2.4G×2 + 5G×4 + AIoT×1）                        |
| 其他功能芯片           | 蓝牙、独立 FEM 等                 | QCA9889                                                   |
| 背板网口               | 网口组合                          | 2.5G×1 + 1G×3                                             |
| USB/SATA               | 接口                              | USB3.0                                                    |
| 交换/PHY               | 交换芯片或 PHY                    | QCA8337-AL3C + QCA8081                                    |

约定：

- 「路由器名称 + 型号」必须唯一，重复会被构建拦下。
- 未知或不适用的字段统一写 `-`，不要留空。
- 无线列写成 `MIMO · 频宽 · 速率 · 调制`，例如 `2×2 · 40MHz · 574Mbps · 1024-QAM`；多频段用 `；` 分隔，构建时会自动换行。
- 天线写成 `数量 根内置/外置`，能确认频段分配或特殊天线时在括号里补充。
- 上市时间写 `2014.4.23`；只查到月份可以写 `2025.6`，只写年份会被提示补全。
- 列顺序不要改；要增删列需同时改 `scripts/build.mjs` 里的 `COLUMNS` 和列分组。

## 本地预览

需要 Node.js 22+：

```console
npm install
npx playwright install chromium   # 首次
npm run build
open output/index.html
```

`npm run build` 会重新生成 `assets/specs-*.png` 和 `output/index.html`，并更新 README 中的统计与图片区块。

- 改了 `data/routers.csv` 后建议重新执行，确认图片排版正常。
- 构建是幂等的；数据没变时重复构建不会产生差异。
- 图片最终由 CI 在 Ubuntu + Noto Sans CJK 下渲染，macOS 本地用 PingFang，字形会有细微差异。提交时带上数据即可，图片和 README 统计可以交给 CI 回写。

## 图片分组

21 列放在一张图里在 README 中会被整体缩小到不可读，因此按用途拆成五张，每张把「路由器名称 + 型号」合成一列作索引：

1. 概览与性能：上市时间、SOC、频率/架构、NPU/加速
2. 内存与存储：内存、内存型号、存储、存储型号
3. 2.4G 无线：2.4G 芯片、2.4G FEM、2.4G 无线
4. 5G 无线：5G 芯片、5G FEM、5G 无线
5. 接口与其他：天线、其他功能芯片、背板网口、USB/SATA、交换/PHY

分组与列宽定义在 `scripts/build.mjs` 的 `GROUPS`、`COLUMN_WIDTH`。

## CI 行为

- 任意分支 push / PR：安装依赖、格式检查、构建（PR 不写回仓库）。
- 仅 `main`：构建后如果图片或 README 有变化，由 `github-actions[bot]` 自动提交；随后部署 `output/` 到 GitHub Pages。
- 机器人提交带 `[skip ci]`，且 job 以 `github.actor != 'github-actions[bot]'` 守卫，不会循环触发。
- 因此即使在网页上直接改 CSV，CI 也会自动补上图片和 README 的更新；本地跑 `npm run build` 只是让改动即时可见。

## 数据来源与批次

- 新增或修改数据时，把用到的链接记到 [`sources.md`](sources.md)，老型号沿用 acwifi 配置表即可。
- 同名不同硬件的型号（BE3600、AX3000T、BE6500 Pro 等）先看 [`variants.md`](variants.md)，表格只记录主批次。
- 拿不准的字段写 `-`，不要用推测值填满。

## 常见问题

**构建报「第 N 行有 X 列，应为 21 列」**：某行多写或少写了逗号，用编辑器打开该行检查。

**构建报「表头与约定不一致」**：表头被改动了，恢复为原始 21 列表头，或同步修改脚本。

**图片里出现方块字**：本地缺少中文字体，macOS 自带 PingFang SC；Linux 安装 `fonts-noto-cjk` 即可。
