# 已知缺口

这份表还有几类没填满的地方。这里把「确实没有」「不适用」「没查到」分开记录，避免用推测值凑数。

## 口径上的缺口

表里的 `-` 目前同时承担三种含义：确认没有、单频不适用、还没查到。这是目前最大的一处口径缺口，计划拆成：

- `无`：确认该型号没有这个部件（例如没有 USB、没有独立 NPU）。
- `不适用`：单频型号没有 5G 射频。
- `-`：还没有可靠来源，属于待补。
- `集成`：无线或交换功能集成在主控/射频芯片内，没有独立芯片。

在拆分完成前，下面的「待补」只列确实缺来源的项；`-` 出现在「无」或「不适用」位置的，不算待补。

## 没有收录的批次

主表一行只记一个主批次，下面这些在 [variants.md](variants.md) 里有说明，但没有单独占一行：

- 小米AX3000T 的 v2（仍为 MT7981B，但交换/闪存/内存换料，具体料号未确认）目前只记在 variants.md，没有单独进主表。
- 小米BE6500 Pro 的 2025.4 起批次已单独进主表；更晚的批次是否还有换料，暂无资料。
- 小米BE3600 千兆版（RD16，2024 高通）与黑色版（AN7563PT）都已单独进主表；黑色批次的首销日期按 2025.11 估算，拆机时间为 2026.6。
- 小米BE3600 Pro 的单只/套装硬件相同，只在备注里区分。

## 可以新增的维度

目前表里没有、但很多人会查的字段：

- 首发价 / 当前参考价。
- 尺寸、重量、待机功耗。
- 是否支持 6GHz、MLO、双 WAN、链路聚合（部分可由网口和芯片推断，但没有逐台核实）。
- 每行的拆机来源链接（现在只在 `docs/sources.md` 里按型号列了主要来源）。

新增列会加宽一图流和拆分图，建议先确认确实需要再加。
